# Roadmap

The roadmap is intentionally outcome-oriented and may change as the independent project matures.

## v2.0 foundation

- Independent Agent Taskboard identity, packaging, documentation, and release gates.
- Stable local-first taskboard and `taskctl` workflows.
- Explicit unsigned-preview handling for desktop platforms.

## Next

- Improve onboarding and manual migration tooling.
- Expand agent workflow examples and integration tests.
- Establish reproducible signed releases when credentials are available.
- Improve accessibility and localization coverage.

Ideas and priorities should be discussed in GitHub Issues before implementation.
