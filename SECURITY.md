# Security policy

Please do not report vulnerabilities in public Issues. Email the maintainer listed in the repository profile with a concise description, affected version, reproduction steps, and mitigation ideas. Do not attach secrets or private user data.

Until a response is available, avoid public disclosure. Agent Taskboard does not promise a response time or security guarantee; this policy describes the preferred reporting path.

Desktop release caveat: macOS and Windows builds are unsigned previews until the project has appropriate signing credentials. Verify checksums and release provenance before installation.
